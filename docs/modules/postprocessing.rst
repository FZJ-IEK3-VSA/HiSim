Postprocessing
==============

The ``hisim.postprocessing`` package produces analysis, visualisation, and
machine-readable exports from a finished HiSim simulation run.

Working Principle
-----------------

After the :mod:`hisim.simulator` completes all timesteps, the postprocessing
stage reads the collected output data and transforms it into charts, key
performance indicators (KPIs), cost and emission summaries, CSV exports, and
an optional PDF report.

The entry point is :class:`~hisim.postprocessing.postprocessing_main.PostProcessor`. Its
:meth:`~hisim.postprocessing.postprocessing_main.PostProcessor.run` method
iterates over :class:`~hisim.postprocessingoptions.PostProcessingOptions`
flags supplied by the caller. Each enabled flag triggers one or more
subroutines:

* **Charts** — line plots, carpet plots, single-day plots, and monthly bar
  charts are generated by :mod:`hisim.postprocessing.charts` and
  :mod:`hisim.postprocessing.chart_singleday` (base class
  :class:`~hisim.postprocessing.chartbase.Chart`).

* **System flow charts** — component network diagrams showing how outputs
  feed into inputs across the whole system are produced by
  :mod:`hisim.postprocessing.system_chart`
  (:class:`~hisim.postprocessing.system_chart.SystemChart`).

* **KPIs** — consumption, production, self-consumption, self-sufficiency,
  and component-specific indicators are computed by the
  :mod:`hisim.postprocessing.kpi_computation` sub-package
  (:class:`~hisim.postprocessing.kpi_computation.compute_kpis.KpiGenerator`,
  which inherits from
  :class:`~hisim.postprocessing.kpi_computation.kpi_preparation.KpiPreparation`)
  and stored on the
  :class:`~hisim.postprocessing.postprocessing_datatransfer.PostProcessingDataTransfer`
  object for downstream use.

* **Costs and emissions** — CAPEX and OPEX are calculated by the
  :mod:`hisim.postprocessing.cost_and_emission_computation` sub-package
  (:func:`~hisim.postprocessing.cost_and_emission_computation.opex_and_capex_cost_calculation.opex_calculation`,
  :func:`~hisim.postprocessing.cost_and_emission_computation.opex_and_capex_cost_calculation.capex_calculation`,
  :class:`~hisim.postprocessing.cost_and_emission_computation.capex_computation.CapexComputationHelperFunctions`)
  and written into the report.

* **CSV / Pickle export** — raw time-series data is written to disk for
  further analysis outside HiSim. Additional CSV exports tailored for
  building-energy databases are produced by
  :mod:`hisim.postprocessing.generate_csv_for_housing_database`
  (:func:`~hisim.postprocessing.generate_csv_for_housing_database.generate_csv_for_database`).

* **PDF report** — the :mod:`hisim.postprocessing.reportgenerator` module
  (:class:`~hisim.postprocessing.reportgenerator.ReportGenerator`) assembles
  all charts and KPI tables into a structured report using ReportLab.
  Figure metadata is carried by
  :class:`~hisim.postprocessing.report_image_entries.ReportImageEntry` and
  :class:`~hisim.postprocessing.report_image_entries.SystemChartEntry`.

* **Scenario evaluation** — the
  :mod:`hisim.postprocessing.scenario_evaluation` sub-package collects,
  processes, and plots aggregated results across multiple simulation runs
  (:class:`~hisim.postprocessing.scenario_evaluation.result_data_collection.ResultDataCollection`,
  :class:`~hisim.postprocessing.scenario_evaluation.result_data_processing.ScenarioDataProcessing`,
  :class:`~hisim.postprocessing.scenario_evaluation.result_data_plotting.ScenarioChartGeneration`,
  :class:`~hisim.postprocessing.scenario_evaluation.scenario_analysis_complete_with_config.ScenarioAnalysisWithConfig`).

Data flows through the
:class:`~hisim.postprocessing.postprocessing_datatransfer.PostProcessingDataTransfer`
dataclass, which carries simulation results, component metadata, and the
active postprocessing option flags from the simulator into every
postprocessing routine.

Sub-packages and Modules
------------------------

* :mod:`hisim.postprocessing.postprocessing_main` — the
  :class:`~hisim.postprocessing.postprocessing_main.PostProcessor` class that
  orchestrates all postprocessing steps.

* :mod:`hisim.postprocessing.postprocessing_datatransfer` — the
  :class:`~hisim.postprocessing.postprocessing_datatransfer.PostProcessingDataTransfer`
  data transfer object shared by all postprocessing routines.

* :mod:`hisim.postprocessing.chartbase` — base class
  :class:`~hisim.postprocessing.chartbase.Chart` for all chart types.

* :mod:`hisim.postprocessing.charts` — line, carpet, and monthly bar chart
  implementations.

* :mod:`hisim.postprocessing.chart_singleday` — single-day chart generation
  via :class:`~hisim.postprocessing.chart_singleday.ChartSingleDay`.

* :mod:`hisim.postprocessing.system_chart` — component network/flow diagram
  generation via :class:`~hisim.postprocessing.system_chart.SystemChart`.

* :mod:`hisim.postprocessing.report_image_entries` — data containers
  :class:`~hisim.postprocessing.report_image_entries.ReportImageEntry` and
  :class:`~hisim.postprocessing.report_image_entries.SystemChartEntry` used
  to describe figures embedded in the PDF report.

* :mod:`hisim.postprocessing.reportgenerator` —
  :class:`~hisim.postprocessing.reportgenerator.ReportGenerator` builds the
  final PDF report with table of contents, charts, and KPI tables.

* :mod:`hisim.postprocessing.kpi_computation` — sub-package containing
  :mod:`hisim.postprocessing.kpi_computation.compute_kpis`
  (:class:`~hisim.postprocessing.kpi_computation.compute_kpis.KpiGenerator`),
  :mod:`hisim.postprocessing.kpi_computation.kpi_preparation`
  (:class:`~hisim.postprocessing.kpi_computation.kpi_preparation.KpiPreparation`,
  data preparation helpers for KPI calculation), and
  :mod:`hisim.postprocessing.kpi_computation.kpi_structure`
  (:class:`~hisim.postprocessing.kpi_computation.kpi_structure.KpiEntry`,
  :class:`~hisim.postprocessing.kpi_computation.kpi_structure.KpiTagEnumClass`).

* :mod:`hisim.postprocessing.cost_and_emission_computation` — sub-package
  containing
  :mod:`hisim.postprocessing.cost_and_emission_computation.opex_and_capex_cost_calculation`
  (:func:`~hisim.postprocessing.cost_and_emission_computation.opex_and_capex_cost_calculation.opex_calculation`,
  :func:`~hisim.postprocessing.cost_and_emission_computation.opex_and_capex_cost_calculation.capex_calculation`)
  and
  :mod:`hisim.postprocessing.cost_and_emission_computation.capex_computation`
  (:class:`~hisim.postprocessing.cost_and_emission_computation.capex_computation.CapexComputationHelperFunctions`).

* :mod:`hisim.postprocessing.scenario_evaluation` — sub-package for
  comparing results across multiple scenarios:
  :mod:`hisim.postprocessing.scenario_evaluation.result_data_collection`
  (:class:`~hisim.postprocessing.scenario_evaluation.result_data_collection.ResultDataCollection`),
  :mod:`hisim.postprocessing.scenario_evaluation.result_data_processing`
  (:class:`~hisim.postprocessing.scenario_evaluation.result_data_processing.ScenarioDataProcessing`),
  :mod:`hisim.postprocessing.scenario_evaluation.result_data_plotting`
  (:class:`~hisim.postprocessing.scenario_evaluation.result_data_plotting.ScenarioChartGeneration`),
  and
  :mod:`hisim.postprocessing.scenario_evaluation.scenario_analysis_complete_with_config`
  (:class:`~hisim.postprocessing.scenario_evaluation.scenario_analysis_complete_with_config.ScenarioAnalysisWithConfig`,
  :class:`~hisim.postprocessing.scenario_evaluation.scenario_analysis_complete_with_config.ScenarioAnalysisConfig`).

* :mod:`hisim.postprocessing.generate_csv_for_housing_database` — produces
  CSV exports tailored for building-energy housing databases via
  :func:`~hisim.postprocessing.generate_csv_for_housing_database.generate_csv_for_database`.
