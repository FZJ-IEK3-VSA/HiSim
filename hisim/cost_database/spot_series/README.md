# Spot price series

## `synthetic_reference_hourly.csv`

**This file is not market data.** It is the output of the deterministic closed-form generator
`hisim.economics.tariffs.synthetic_reference_spot_series()` (defaults: mean 0.08 EUR/kWh,
amplitude 0.04 EUR/kWh) — a daily sine with morning/evening structure plus a 20 % seasonal
term, floored at zero, 8760 hourly values, rounded to six decimals. It was authored as a test
fixture, not generated by an AI and not derived from any exchange series.

It exists because real day-ahead series (EPEX and similar) cannot be redistributed for
licensing reasons (cost_spec.md Q16), while the DYNAMIC contract machinery still needs a series
to be exercised end to end — including the CSV loader path this file feeds. Its source entry in
`../sources.json` (the `DE_DYNAMIC_SYNTHETIC_2024` fixture source) carries the same statement.

`tests/test_economics_database.py::TestSpotSeriesProvenance` asserts row by row that this file
equals the generator's output, so any edit that would silently turn the fixture into something
else fails CI.

**Never back a published result with this profile.** For real studies, supply your own series
as a one-column CSV (header `price_in_euro_per_kwh`, 8760 hourly rows) in this directory and
reference its file stem as the contract's `spot_series`.
