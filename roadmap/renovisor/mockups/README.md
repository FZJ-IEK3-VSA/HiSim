# Mockups

The request round-trip mockups that used to live here are gone. The one worked example the
translation layer uses is the frontend side's own
`hisim/renovisor/contract/calculation-request.mockup-1.yaml`, vendored with its hash in
`PINNED.yaml`: it is the anchor of the capability document's probe set, the fixture of the
end-to-end tests, and the trace on `roadmap/renovisor/translation_map.html`. One example that
both sides of the contract point at is worth more than three that only one side maintains.

What is left here is not a request: `heat_pump_household.energy_system.yaml` is an
energy-system file and `measures.schema.yaml` is the superseded discriminated-union proposal,
kept for the decisions recorded in its footer.
